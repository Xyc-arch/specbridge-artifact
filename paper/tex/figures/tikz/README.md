# Legacy diagram sources

any more. The paper's diagrams are built from `../src/diag_*.tex` with pdfLaTeX (`../src/README.md`), and
`specbridge.report.datamap_tex` now writes `../src/diag_datamap.tex`, so `datamap.tex` here is its last legacy output.
